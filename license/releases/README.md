# TOIL Release Evidence (SHA-256)

This folder contains SHA-256 manifests for canonical TOIL legal artifacts.

Purpose:
- Provide evidence-grade pinning of the exact text used for a given release.
- Reduce ambiguity during enforcement and audits.

How to use:
- Each release should include a manifest file listing SHA-256 hashes for canonical documents.
- Tag the repo after manifests are committed.
