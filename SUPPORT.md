# Support

This repository contains the Tech4Life Open Impact License (TOIL), official templates, and release verification tooling.

## What we support here
- TOIL license text and amendments (`license/`, `AMENDMENTS.md`)
- Release integrity tooling (`tools/`)
- Official legal templates (`templates/`)
- Documentation and release process (`README.md`, `RELEASING.md`, `CHANGELOG.md`)

## How to get help
1. Open a GitHub Issue with:
   - A clear title and description
   - The relevant file path(s)
   - Steps to reproduce (if tooling-related)
   - CI logs or command output (copy/paste)

## Confidentiality
Do not include private partner terms, internal royalty splits, or any private/legal/finance repository content.

## Maintainers
Changes to license text, templates, and release tooling require CODEOWNERS review.
