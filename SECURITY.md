# Security Policy

TOIL is a legal and governance repository. Security issues can still occur, including:
- leaked secrets or personal data
- malicious links or unsafe guidance
- document tampering or unauthorized legal drift
- supply-chain or provenance integrity gaps for released texts

## Reporting

Please do not open public issues for security-sensitive reports.

Preferred:
1. GitHub Security Advisories (if enabled).
2. If advisories are not available: open an issue titled **"SECURITY (PRIVATE REQUEST)"** with **no sensitive details**, and request a private channel.

Include:
- Description of issue
- File path(s)
- Impact
- Suggested remediation (if known)

## Disclosure posture

We will:
- acknowledge receipt as soon as practical
- coordinate a fix
- publish a disclosure note when appropriate
